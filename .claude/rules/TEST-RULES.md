Escreva testes unitários para regras de negócio importantes.

Teste o comportamento dos serviços independentemente do HTTP e da implementação do banco sempre que possível.

Adicione testes de integração para fluxos críticos da API e do banco de dados.

Teste autenticação, autorização, validação e cenários de falha.

Utilize o framework de testes já configurado no projeto.

Execute lint, verificação de tipos, testes e builds quando disponíveis.

Não remova testes apenas para fazer o build passar.

Não desative verificações do TypeScript ou regras de lint para ocultar problemas.

Evite mocks excessivos que tornem os testes pouco representativos.
